# Woord – Niederländisch lernen

Direkt lernen: https://focusframedigitalwebdesign.github.io/chemie/woord/

Vokabeln, Grammatik und Arbeitsvorbereitung. Der Lernfortschritt und eigene Texte werden ausschließlich im lokalen Browser gespeichert (localStorage), ohne Login oder Serverübertragung. Beim Löschen der Browserdaten wird der Fortschritt entfernt. Die Android-App hat einen eigenen lokalen Speicher.

Android: [Woord-Nederlands.apk](./Woord-Nederlands.apk)

Die Web-App ist eine eigenständige HTML-Datei. Sie benötigt keine externen Skripte oder einen Backend-Server.
